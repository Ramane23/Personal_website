# Project Preview Images

Place your project preview/screenshot images in this directory.

## Required Images

1. **contrails-preview.png** - Real-Time Contrails Prediction System preview/screenshot
2. **blog-generator-preview.png** - AI-Powered Blog Generator Agent preview/screenshot
3. **ai-chatbots-preview.png** - AI Chatbots preview/screenshot
4. **homematch-preview.png** - HomeMatch RAG preview/screenshot

## Recommended Specifications

- **Format**: PNG or JPG
- **Dimensions**:
  - Width: 800px - 1200px
  - Height: 400px - 600px (will be cropped to 192px height in card view)
  - Aspect ratio: ~16:9 or 2:1 works best
- **Content**:
  - Screenshot of application UI
  - Dashboard view
  - Key features visualization
  - Data visualization/charts
  - Or any compelling visual that represents the project

## How Images are Used

These images appear at the top of each project card as a preview/hero image with:
- Fixed height of 192px (h-48)
- Full width
- Cover object-fit (will crop to fill)
- Hover zoom effect (scales to 105% on hover)
- Background color fallback if image doesn't load

## Tips

- Use high-quality screenshots
- Ensure important content is centered (due to cropping)
- Avoid text that's too small to read at card size
- Consider using visually appealing data visualizations or UI elements
- Test how the image looks when cropped to 192px height
