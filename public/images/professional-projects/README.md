## Recommended Specifications

- **Format**: PNG or JPG
- **Dimensions**: 800px minimum width, height will auto-adjust
- **Style**: Professional architecture diagrams with:
  - Database symbols (cylinders)
  - Colored component boxes for different layers
  - Labeled data flow arrows
  - Technology logos where applicable
  - Grouped sections with dotted borders
  - Clear system boundaries and interactions

## How Images are Used

These images are displayed in the expandable "Featured Projects" section under each work experience. When a user clicks on a project name, the architecture diagram appears along with detailed technical descriptions.

## Content Suggestions

Each diagram should clearly show:
- **Data flow**: How data moves through the system
- **Key components**: Major services, databases, APIs
- **Technology stack**: Real logos/icons of frameworks used
- **System boundaries**: Clear separation of different layers/modules
- **Integration points**: How different parts connect
