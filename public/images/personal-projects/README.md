## Recommended Specifications

- **Format**: PNG or JPG
- **Dimensions**: 700px width (minimum), height will auto-adjust
- **Style**: Professional architecture diagrams with:
  - Database symbols (cylinders)
  - Colored component boxes
  - Labeled data flow arrows
  - Technology logos
  - Grouped sections with dotted borders

## How Images are Used

These images will be displayed in the project cards on the portfolio website under the "Architecture Diagram" section. They help visualize the system design and data flow for each project.
